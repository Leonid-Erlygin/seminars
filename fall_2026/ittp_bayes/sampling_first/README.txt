Сэмплирование. Семинар 1
ИППИ РАН · Байесовские методы машинного обучения · Осень 2026

Формат занятия: 60 минут выводов на доске и 30 минут демонстрации
полностью заполненного ноутбука. Материалы на русском; подписи графиков
на английском, как в примерах Skoltech.

Основные файлы
  sampling_first_teachers_guide.pdf   Скомпилированный конспект преподавателя.
  sampling_first_teachers_guide.tex   Редактируемый LaTeX-исходник конспекта.
  sampling_first_solutions.ipynb      Заполненные реализации и сохранённые выводы.
  assets/                            Четыре векторных рисунка для конспекта.

Для воспроизведения
  build_sampling_notebook.py          Исходник ноутбука с формулами и кодом.
  execute_notebook.py                 Запуск с чистого ядра и сохранение результатов.
  build.sh                           Полная пересборка ноутбука, рисунков и PDF.
  requirements.txt                   Зависимости Python.
  validation.json                    Результаты фактической проверки.

У доски
  0–6 минут:   байесовские интегралы и независимый Monte Carlo.
  6–18:        метод отклонений; доказательство; постериор Beta(3,7).
  18–33:       матрица перехода, стационарность, неприводимость, периодичность.
  33–42:       детальное равновесие; что оно доказывает и чего не обеспечивает.
  42–60:       полные условные распределения; Гиббс; нормальный пример.

В ноутбуке
  0–8 минут:   геометрия отклонений и точные постериорные ориентиры.
  8–15:        конечные цепи; периодический и приводимый контрпримеры.
  15–30:       Гиббс при rho=.5,.95,.99; траектории, ACF, ESS и MCSE.
  Приложение:  нормальная модель с неизвестными средним и точностью.
               Не входит в основной тайминг, но также заполнено и выполнено.

В ноутбуке одна итерация Гиббса — полный проход x, затем y.
Случайный выбор координаты разбирается в теории; основной код использует
последовательный обход. Стационарность, сходимость законов и сходимость
средних обсуждаются отдельно. Полный проход сохраняет целевой закон,
хотя в общем случае не удовлетворяет детальному равновесию.

Независимые значения метода отклонений сравниваются с точным постериором.
В главном опыте Гиббса старт стационарный: он отделяет корреляцию от
начального смещения. Отдельный рисунок показывает различные старты.
В основной выборке прореживания нет; burn-in используется в приложении.

Запуск для занятия
  Откройте sampling_first_solutions.ipynb в Jupyter или VS Code.
  Результаты уже сохранены; перед занятием выполните Restart Kernel / Run All.
  Данные генерируются локально. GPU, интернет и внешние датасеты не нужны.
  Для чтения ноутбука отдельно достаточно самого .ipynb: графики сохранены
  в выводах. Для компиляции .tex нужна соседняя папка assets/.

Повторная сборка (Python 3.9+)
  python -m pip install -r requirements.txt
  ./build.sh
  Требуется pdflatex с русским babel, T2A, CM-Super и пакетами преамбулы
  либо Tectonic с доступным TeX bundle. PDF собирается из LaTeX.

Отдельные шаги
  python build_sampling_notebook.py
  python execute_notebook.py
  pdflatex -interaction=nonstopmode -halt-on-error sampling_first_teachers_guide.tex
  pdflatex -interaction=nonstopmode -halt-on-error sampling_first_teachers_guide.tex

build_sampling_notebook.py пересоздаёт .ipynb и очищает его выводы.
execute_notebook.py выполняет все ячейки, проверяет формат и сохраняет
успешный результат; ошибки не скрываются. Выполнение создаёт рисунки assets/.
Изменения содержания вносите в build_sampling_notebook.py, затем пересобирайте.
Численные оценки одной реализации могут немного отличаться между версиями
библиотек. Проверки используют аналитические тождества, а не требование
случайно попасть достаточно близко к точному среднему.

Первый семинар ограничен методом отклонений, цепями и Гиббсом.
Метрополис, Метрополис–Гастингс, его связь с Гиббсом и гамильтонова
динамика оставлены для второго семинара. Источники указаны в конспекте
и в конце ноутбука.
