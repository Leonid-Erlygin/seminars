ИППИ РАН · Байесовские методы машинного обучения · осень 2026

Семинар рассчитан на 120 минут. Приложения про транспортное расстояние,
выбор числа компонент и VAE можно вынести на самостоятельную работу.

Порядок работы
  1. E-шаг, M-шаг и цикл EM для диагональной гауссовской смеси.
  2. Игрушечные примеры; мягкие назначения, ковариации, монотонность цели.
  3. EM для смеси мультиномиальных распределений: один объект — вся гистограмма.
  4. Открытая задача: предложить и сравнить методы кластеризации распределений.

Основные данные: 720 гистограмм с 64 общими бинами; 480 объектов для обучения
и 240 для теста. Четыре базовые формы имеют одинаковые теоретические среднее
и дисперсию до случайных сдвигов, растяжений и обрезания хвостов. Это позволяет
исследовать признаки формы, геометрию Хеллингера и шум конечных выборок.
Число семейств K=4 задано учебным условием. Истинные метки нужны только для
заключительного аудита, после фиксации методов и параметров.

Запуск
  python -m pip install -r requirements.txt
  Затем откройте нужный .ipynb в Jupyter/VS Code и выполните ячейки по порядку.
  Для приложения VAE дополнительно установите torch и задайте RUN_VAE=True.
  В заполненной версии VAE уже выполнен на CPU; GPU и сеть не нужны.

Незавершённые реализации в студенческой версии вызывают NotImplementedError.
Проверки сообщают, что задание ещё не заполнено; зависимые опыты пропускаются.
После реализации повторно выполните функцию, проверку и зависимые ячейки.
Студенческий файл сохранён без выводов и без ответов в заданиях.
Рисунки и таблицы заполненного файла получены реальным выполнением кода.

Сборка конспекта из этой папки
  pdflatex -interaction=nonstopmode -halt-on-error em_teachers_guide.tex
  pdflatex -interaction=nonstopmode -halt-on-error em_teachers_guide.tex
  Нужны пакеты, перечисленные в преамбуле .tex, поддержка T2A, русский babel,
  русские переносы и масштабируемые шрифты CM-Super. Сеть при чтении PDF не нужна.

Редактирование двух версий ноутбука
  python build_notebooks.py
  Команда пересоздаёт оба .ipynb и очищает сохранённые выводы решений.
  После неё заново выполните заполненную версию. Для раздачи студентам
  достаточно student.ipynb; build_notebooks.py содержит эталонные решения.

Проверено: обе версии полностью выполняются с чистого ядра; аналитические
проверки реализованных методов проходят. Версии библиотек и результаты
зафиксированы в validation.json и в выводах заполненного ноутбука.
Численные значения не являются порогами оценивания и могут немного отличаться
при других версиях библиотек. Данные и все эксперименты — учебная симуляция.
